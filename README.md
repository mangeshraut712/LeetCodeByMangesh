## Overview

This repository is a personal LeetCode notebook: each problem lives in its own directory with a solution file and a companion README. The layout makes it easy to revisit a problem, compare implementations, or browse by topic and language.

## Repository Layout

- Each problem folder is named with the LeetCode problem number and slug.
- Most folders include a `README.md` plus the solution source file.
- Problem statements, reasoning, and code sit together in one place.

## Languages

- Python for the bulk of the solutions.
- JavaScript for array and utility problems.
- Swift for a few language-specific exercises.
- SQL for query-based challenges.
- Java for tree and graph problems.

## How to Use

1. Open the folder for the problem you want to review.
2. Read the local `README.md` for the approach and complexity notes.
3. Run or adapt the solution file in your preferred runtime if you want to experiment locally.

## Adding a Solution

1. Create a new folder using the problem number and slug.
2. Add a short `README.md` that explains the approach.
3. Add the solution file in the language you used.
4. Keep the naming and structure consistent with the existing folders.
